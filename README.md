# 🚨 Smart Emergency Response & Disaster Management Platform

## 📌 Overview
The Smart Emergency Response & Disaster Management Platform is a web-based application designed to support emergency reporting, incident monitoring, and disaster response coordination.

The platform aims to provide a simple and accessible way to report emergencies and help responders monitor incidents through a centralized dashboard.

## 🎯 Objectives
- Enable quick and easy emergency reporting.
- Provide a centralized platform for incident management.
- Support emergency response coordination.
- Display incident information through an interactive dashboard.
- Improve awareness and monitoring during emergency situations.

## ✨ Features
- **Emergency Reporting:** Report emergency incidents through the platform.
- **Incident Management:** View and manage reported incidents.
- **Emergency Dashboard:** Monitor incident information and response status.
- **Emergency Map:** Display incident locations.
- **Response Team Management:** View and manage response teams.
- **Incident Tracking:** Track incident progress and status.
- **User-Friendly Interface:** Simple and accessible design.

## 🛠️ Technologies Used
- **Python** – Backend development
- **Flask** – Web application framework
- **HTML** – Webpage structure
- **CSS** – Styling and layout
- **JavaScript** – Frontend interactions
- **SQLite** – Database
- **Git & GitHub** – Version control and project hosting

## 🚀 Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Hema-Sanjeevan-KV/Emergency-Response-AI.git
```

### 2. Navigate to the Project Directory
```bash
cd Emergency-Response-AI
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
python app.py
```

### 5. Open in Browser
Visit:

```text
http://127.0.0.1:5000
```

## 💻 Application Workflow
1. Open the emergency response platform.
2. Report an emergency incident.
3. View incident information on the dashboard.
4. Monitor incident locations through the map.
5. Manage incident status and response teams.
6. Track emergency response progress.
